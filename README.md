# Next TypeScript Boilerplate

A Next.js 13 and React 18 starter with TypeScript, styled-components, Jest, Testing Library and Storybook.

## Getting started

```bash
npx degit gcardoso23/next-typescript-boilerplate my-app
cd my-app
yarn
yarn dev
```

## Scripts

| Command           | What it does                  |
| ----------------- | ----------------------------- |
| `yarn dev`        | Start the dev server          |
| `yarn build`      | Build for production          |
| `yarn test`       | Run the tests                 |
| `yarn lint`       | Lint with Next's ESLint rules |
| `yarn type-check` | Check types with TypeScript   |
| `yarn storybook`  | Start Storybook on port 6006  |
